# Witch It UE4SS host

This branch contains the Witch It host and Lua integration used by Witch It+.
Players: install [Witch It+ Core](https://github.com/monroth/WitchItPlus-Core), then the features linked there. Core includes the matching loader and native components.
Close the game before installing or updating. Extract the release ZIP's Win64 contents into WitchIt/Binaries/Win64 and keep a backup. The Core README explains updates and settings.

The upstream LICENSE is preserved. Dependency licenses remain with their sources.
